# ORBIT BREAKER

`index.html` をブラウザで開くだけで遊べる（依存ゼロ・単一ファイル・スマホ対応）。

## 遊び方

- 自機は恒星のまわりを自動で周回する
- **クリック / タップ / スペース**: 軌道チェンジ（内→中→外→内の循環）
- 光るアークに当たると死。出現直後の薄いアークは当たり判定なし（予告）
- 金の◆を取るとスコア。4秒以内に連続で取るとコンボ倍率（最大×8）
- 水色の◆はシールド（1回だけ被弾を無効化）
- 時間経過で速度・出現頻度が上がる。ベストスコアは localStorage 保存
- **M**: ミュート

## 技術メモ（判断の記録）

- 題材は「1ボタンで遊べて、スコアアタックで深さが出る」軌道アーケードに決めた
- Canvas 2D + WebAudio（BGM・効果音も全て手続き生成、音声ファイルなし）
- パーティクル、画面シェイク、スローモーション死亡演出、色相が時間で変化するパレット
- フェアネス設計: 障害物は0.6秒の予告フェードイン後に有効化、自機の進行方向直近には湧かない
- 検証: node --check ＋ Playwright ヘッドレスで実プレイ（JSエラーなし、Game Over 遷移確認済み）
